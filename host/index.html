What it does

A FastAPI web app that turns natural-language questions into SQL using Anthropic Claude, runs them against a SQLite database, and returns results with charts, explanations, and follow-up suggestions. It ships with a pre-seeded 8-table e-commerce database and a dark SQL IDE UI. Useful for analysts and developers who want to explore a SQLite dataset without hand-writing queries.

Highlights

Every item below is implemented in the repo.

  • Natural language to SQL with prompt caching

    Questions are translated to SQL by Claude (default model claude-sonnet-4-6). The database schema is sent in a cache_control ephemeral block so repeat requests reuse the cached schema tokens.

  • SELECT-only safety guard

    Generated SQL must start with SELECT and is rejected if it contains DROP, DELETE, INSERT, UPDATE, CREATE, ALTER, TRUNCATE, REPLACE, ATTACH, DETACH, or PRAGMA. Blocking happens before execution.

  • Schema explorer and Mermaid ERD

    Endpoints introspect primary keys, foreign keys, indexes, and row counts into a structured schema summary, and generate a Mermaid ER diagram rendered in the browser.

  • Explain and optimize queries

    POST /explain returns a plain-English walkthrough of a SQL statement; POST /optimize returns optimization suggestions plus an optional rewritten query. Both are Claude-backed and receive the schema as context.

  • Automatic chart suggestion

    A heuristic engine inspects column types and result shape to pick bar, line, pie, scatter, or table, then emits Chart.js-ready labels and datasets along with the reason for the choice.

  • History, saved queries, and exports

    Every query is logged to a separate metadata SQLite database with duration and row count, and can be searched, fetched, or deleted; queries can be saved by name. Result sets export to CSV, JSON, Markdown, or Excel (.xlsx).

Run it locally

You supply your own API key, so nothing is billed to anyone else and no key ships in this repo.

shell 
$ git clone https://github.com/kanizmadix/ai-sql-assistant.git
$ cd ai-sql-assistant
$ cp .env.example .env
# edit .env and set ANTHROPIC_API_KEY=sk-ant-...
$ python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
$ python sample_data.py
$ uvicorn main:app --reload --port 8000
# open http://localhost:8000

Configuration

Set these in your local .env. Never commit real values.
VariableStatusPurpose
ANTHROPIC_API_KEYrequiredAnthropic API key; SQL generation, explain, optimize and follow-ups fail without it.
MODELoptionalClaude model id. Defaults to claude-sonnet-4-6.
DATA_DB_PATHoptionalPath to the queried SQLite data file. Defaults to ./ecommerce.db.
META_DB_PATHoptionalPath to the metadata SQLite database holding query history and saved queries. Defaults to ./metadata.db.
LOG_LEVELoptionalStructured JSON log level (DEBUG, INFO, WARNING, ERROR). Defaults to INFO.
RATE_LIMIT_CAPACITYoptionalToken-bucket size per client IP. Defaults to 60.
RATE_LIMIT_REFILL_PER_SECoptionalToken refill rate per second for the rate limiter. Defaults to 1.0.

API surface

Available once the server is running on your machine.

MethodPathDescription
POST/queryTranslate a natural-language question to SQL, execute it, and log the run to history.
POST/optimizeReturn optimization suggestions and an optional rewritten version of a SQL query.
POST/explainExplain a SQL query in plain English using the database schema as context.
GET/schema/{db_name}/erdGenerate a Mermaid ER diagram for a registered database.
POST/chart-suggestSuggest a chart type and Chart.js labels/datasets for given columns and rows.
POST/export/{format}Download a result set as csv, json, markdown, or excel.
GET/historyPaginated query history; also supports search, fetch by id, and delete.
POST/followupSuggest follow-up natural-language questions from a question and its result set.

Why this page isn't the app itself

GitHub Pages only serves static files, while this project needs a running Python/FastAPI server with SQLite access and a secret ANTHROPIC_API_KEY, so it cannot be hosted there.

This page is a static overview served from the repo's host/ folder on GitHub Pages. Clone the repo and follow the steps above to run the real thing.
